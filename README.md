# Signalist: Real-Time Stock Analysis Platform

Signalist is a modern, full-stack web application designed to provide users with real-time stock market data, personalized watchlists, and AI-driven insights. Built with a powerful stack including Next.js, TypeScript, and MongoDB, it offers a fast, responsive, and feature-rich experience for tracking the stock market.

### ✨ [Live Demo](https://stockanalysis-pro.vercel.app/) ✨

## 🚀 Key Features

* **📈 Real-Time Market Data:** View live market overviews, stock heatmaps, and detailed financial information powered by the Finnhub API.
* **👤 User Authentication:** Secure sign-up and sign-in functionality for a personalized experience, built with `better-auth`.
* **⭐ Personalized Watchlists:** Users can add and remove stocks from their personal watchlist to track their favorite companies.
* **🔍 Advanced Stock Search:** A powerful and fast search command to find stocks by symbol or company name.
* **🤖 AI-Powered Emails:**
    * **Personalized Welcome:** New users receive a custom welcome email generated by Google Gemini, tailored to their investment profile.
    * **Daily News Summaries:** Inngest-powered background jobs fetch market news, use AI to summarize it, and email users a daily digest.
* **📊 Interactive Charts:** In-depth company pages with detailed charts and technical analysis widgets from TradingView.
* **Modern Tech Stack:** Built with the Next.js App Router for optimal performance and developer experience.

## ⚙️ Getting Started

Follow these instructions to set up the project on your local machine.

### Prerequisites

* [Node.js](https://nodejs.org/) (v18 or later)
* [Git](https://git-scm.com/)
* A free [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) account
* A free [Inngest](https://www.inngest.com/) account
* API key from [Finnhub](https://finnhub.io/)

### Installation & Setup

1.  **Clone the repository:**
    ```bash
  git clone https://github.com/RachitShahrawat/SignalList.git
  cd SignalList
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Set up environment variables:**
    Create a file named `.env.local` in the root of the project and add the following variables. You can get these keys from their respective services.

    ```env
    # MongoDB
    MONGODB_URI="your_mongodb_connection_string"

    # Finnhub API Key
    NEXT_PUBLIC_FINNHUB_API_KEY="your_finnhub_api_key"

    # better-auth
    BETTER_AUTH_SECRET="generate_a_strong_secret_string" # You can generate one with `openssl rand -base64 32`
    BETTER_AUTH_URL="http://localhost:3000"

    # Inngest
    INNGEST_KEY="your_inngest_key_from_the_dashboard"
    INNGEST_SIGNING_KEY="your_inngest_signing_key"
    
    # Google Gemini API Key
    GEMINI_API_KEY="your_gemini_api_key"

    # Nodemailer (using Gmail)
    NODEMAILER_EMAIL="your_gmail_address"
    NODEMAILER_PASSWORD="your_gmail_app_password" # Important: Use an App Password, not your regular password
    ```

4.  **Run the development servers:**
    This project requires two terminals running simultaneously.

    * **Terminal 1: Start the Next.js application**
        ```bash
        npm run dev
        ```
        Your application will be available at `http://localhost:3000`.

    * **Terminal 2: Start the Inngest dev server**
        ```bash
        npx inngest-cli dev
        ```
        This creates a secure bridge to the Inngest cloud for local development.

## 🚀 Deployment

This application is optimized for deployment on [Vercel](https://vercel.com/).

Simply connect your GitHub repository to Vercel and it will automatically deploy. Remember to add all the environment variables from your `.env.local` file to the Vercel project settings.
